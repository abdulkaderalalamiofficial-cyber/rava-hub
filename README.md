# Lean Launchpad

أنا قمت برفع ملف الـ Super App المضغوط. أريدك أن تقوم بتهيئة وتشغيل المشروع بأعلى كفاءة وأقل استهلاك ممكن للنقاط (Token Efficiency)، مع الالتزام التام بالبنية الحالية. اتبع الآتي:



1. [قراءة الهيكل فقط أولاً]: ارفع الملفات واقرأ هيكل المشروع والمكتبات الأساسية (Dependencies) فقط دون تعديل أو توليد أكواد جديدة لتوفر في الاستهلاك.

2. [التشغيل التدريجي الموفر]: قم بتشغيل التطبيق والصفحات خطوة بخطوة. لا تقم بإعادة كتابة أي كود سليم وموجود بالفعل داخل الملف المضغوط.

3. [الفحص الذاتي الذكي]: قبل عمل أي Preview، تأكد من عدم وجود أخطاء برمجة (Compile errors). إذا وجدت خطأ، أصلحه في نفس السطر مباشرة بدلاً من إعادة توليد الصفحة كاملة.

4. [الحفاظ التام على الهوية]: التزم بالأزرار، التنقلات، والخرائط الموجودة بالحرف، ولا تقم بابتكار أي ميزات إضافية من عندك تستهلك نقاط المحادثة.



ابدأ الآن بتهيئة البيئة بأقل استهلاك، وأعلمني عندما يكتمل التشغيل.
